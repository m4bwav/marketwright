# One skill, its own plugin, and the name

**Shape: one skill with four procedures, not a hub with siblings.** The kickoff suggested a hub plus `-store`, `-trailer` and `-reach` siblings. ludowright's decision of 2026-10-29 applies here too: Agent Skills linters reject links that leave a skill folder, so siblings would each need a copy of the kb, and each sibling adds an always-loaded description. The four tasks fit one description (1,060 characters). The procedures sit in `references/`. Revisit if a trigger eval shows one task under-triggering.

**Own plugin, not a gamewright sibling.** gamewright exists only as a backlog idea for design work; ludowright already owns design. Marketing is a different job with a different clock (store pages, festivals, law), its own evergreen tier (fast, 21 days) and its own beat. The backlog's "Steam store page" item under gamewright moves here.

**Name (proposed, waiting for the owner).** Kept `marketwright`: plain, matches the suite's -wright names and the backlog. Considered: `launchwright` (too narrow: much of the work is months before launch), `heraldwright` (evocative, less findable), `wishwright` (only wishlists). The name is used in the repo, the beat's `feeds` line and the evergreen unit, so a rename touches those three.

**Status: proposed.** Recorded in HANDOFF.md as an open decision for the owner.
