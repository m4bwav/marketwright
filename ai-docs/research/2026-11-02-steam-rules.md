# Steam rules for honest indie marketing (checked 2026-11-02)

Every fact below was read on a Steamworks page on 2026-11-02, using WebFetch (a page summary, not the raw HTML). Each section names its source. Items marked UNVERIFIED were not found on a primary page. Re-check the page before quoting a number to a user.

## 1. Store page graphical assets

Sources: [S1], [S2], [S3], [S4].

| Asset | Size (px) | Required | Notes |
|---|---|---|---|
| Header capsule | 920 x 430 | Yes | Top of store page, recommendations, Daily Deals. Smaller sizes made from it. |
| Small capsule | 462 x 174 | Yes | Search, top sellers, new releases. Logo should nearly fill it. |
| Main capsule | 1232 x 706 | Yes | Front page carousel. |
| Vertical capsule | 748 x 896 | Yes | Front page during seasonal sales, sale pages. |
| Page background | 1438 x 810 | Optional | Ambient. If missing, Steam builds one from your last screenshot. |
| Bundle header | 707 x 232 | Bundles only | |
| Library capsule | 600 x 900 | Yes | Logo required, subtitle allowed, no other text. |
| Library hero | 3840 x 1240, .png | Yes | Artwork only, no words. |
| Library logo | 1280 wide and/or 720 tall, .png | Yes | Logotype on transparent background, no other words. |
| Library header capsule | 920 x 430 | Yes | |
| Event cover | 800 x 450 | Yes (for events) | |
| Event header | 1920 wide x 622 | Optional | |

- Larger asset sizes started in August 2024. The page says "Old dimensions are no longer accepted." [S2]
- Screenshots: at least 5. Minimum 1920 x 1080, 16:9. [S1]
- Screenshots should show gameplay only. No concept art, pre-rendered cinematic stills, awards, marketing copy. [S1]
- At least four screenshots should be marked "suitable for all ages", or the game may not show in some areas. [S1]
- Accepted image file formats for capsules: UNVERIFIED (not stated on the pages read, except .png for hero and logo).

### What may appear on capsules [S3]

- Base capsules: only game artwork, the game name, and any official subtitle.
- Not allowed: review scores, award names or logos, discount text ("On Sale Now"), calls to action ("Prepurchase Now", "Wishlisting now available"), promotion of other products including sequels, other text.
- Temporary text goes in an Artwork Override. Limit one month. Text must be localised into at least the game's supported languages. It must describe content already available ("DLC now available!"). No "Wishlist now!" or "Available Oct 4th".
- All artwork must be PG-13 appropriate.
- These rules took effect on September 1, 2022. Non-compliant games may lose visibility and be ineligible for official sales and events.

### Trailers [S4]

- Containers: .mov, .wmv, .mp4. H.264 video and AAC audio preferred.
- Up to 1920 x 1080, 30/29.97 or 60/59.94 fps, 5,000+ Kbps. 16:9 preferred, 4:3 accepted. Audio 44 or 48 kHz.
- The first two valid trailers show before screenshots. No stated maximum count.
- Valve "highly recommends" the first trailer be mostly gameplay. Not enforced.
- Custom thumbnail: a frame from the video, 1920x1080 .jpg or .png, avoid text.
- Steam builds a 6-second micro trailer from the first visible video. You cannot customise it.
- You cannot release while a trailer is still converting.

## 2. Store page text, tags, Coming Soon, release

Sources: [S5], [S6], [S7], [S8].

- Short description: the doc says "limited to a few hundred characters". Exact count UNVERIFIED on the primary page. Plain text only. Avoid time-bound phrases like "Now Available". [S5]
- About This Game: images under 5MB each. Keep all screenshots and GIFs under 15MB total. [S5]
- No links to other sites in the description (no QR codes or written domains either). No fake Steam UI (fake wishlist or buy buttons, fake prices). No promoting other games. [S5]
- Localisation: text inside images must be translated and re-uploaded, so textless images are recommended. [S5]
- Tags: at least 5 required before launch. Up to 20 recommended. Only the top 20 are visible and used. Some filters prioritise the first 15. Order sets starting weight. Players and moderators also tag, and player tagging shifts weights. Set in the Tag Wizard. [S6]
- Coming Soon: page must be up at least two weeks before release for new products. [S7] [S8]
- Store page review: submit at least 7 business days before you want the page live [S7]. Review "typically takes 3-5 business days" [S8].
- Release: approved games do not launch on their own. You press "Release App". The build must also be reviewed. [S8]
- Release date display: you control how specific the date is. Details are on a Release Dates doc, not read here (UNVERIFIED detail).

## 3. Steam Next Fest and themed fests

Sources: [S9], [S10].

- Eligibility: never joined a Next Fest before (one fest per game). Base game store page public. Publicly playable demo by fest start. Not released before the fest ends. Developer account in good standing. [S9]
- Demo is a demo-type app attached to the base game. Registration is done from the base game. [S9]
- Demo review deadlines: at least 5 weeks before the fest if releasing the demo for Press Preview, 3 weeks before if releasing it for the fest. Release at least 30 minutes before start. [S9]
- Press Preview includes all registered games and begins 11 days before the fest. [S9]
- Next Fest runs three times a year: February, June, October. [S9]
- Listed dates: February 22 - March 1, 2027 and June 14 - 21, 2027. [S10]
- 2026 editions and their dates: UNVERIFIED (the events page no longer lists them; the October 2026 one has passed).
- Registration deadlines for 2027: UNVERIFIED (not on the pages read; the edition pages gave no dates in the summary).
- Themed fests: each has a "Registration details" opt-in link on the Upcoming Steam Events page and its own eligibility. Discounted games are prioritised; free games, Coming Soon titles and games with demos are also welcome. [S10]
- Listed themed fests: Auto-Battler RPG Fest Nov 16-23 2026; Desktop Companion Fest Jan 14-18 2027; Shop Keeper Fest Jan 25-Feb 1 2027; Sheep Fest Feb 4-8 2027; Couch Co-Op Fest Feb 8-15 2027; Rhythm Fest Mar 8-15 2027; Dinos vs. Robots Fest Mar 29-Apr 5 2027; Racing Fest Apr 12-19 2027; Witch Fest Apr 22-26 2027; Fighting Fest Apr 26-May 3 2027; Real-Time Strategy Fest May 10-17 2027; Mountaineering Fest May 31-Jun 3 2027. Steam Scream V ran Oct 26-Nov 2 2026. [S10]
- Seasonal sales: Winter Sale Dec 17 2026 - Jan 4 2027; Spring Sale Mar 18-25 2027; Summer Sale Jun 24 - Jul 8 2027; Autumn 2027 TBD. Games released at least 30 days before the start are eligible. [S10]

## 4. Visibility

Source: [S11], plus [S12] for demos.

- Wishlisters get an email when the game launches, when it leaves Early Access, and when it is discounted 20% or more. [S11]
- Wishlists are not a factor in algorithmic visibility, "with a few exceptions like the Popular Upcoming tab". [S11]
- Update Visibility Rounds still exist. They show major updates on the front page to owners and wishlisters. Use them only after launch visibility ends, or two weeks after launch in Early Access. No stated limit on frequency. [S11]
- Discovery Queue: only mentioned; titles "might" appear there. Mechanics UNVERIFIED.
- Upcoming list mechanics: UNVERIFIED (not covered on the page).
- A demo can trigger wishlist notifications once, within 14 days of first release. Wishlist notifications have a two-week cooldown per App ID. [S12]

## 5. Discounts

Source: [S13].

- Launch discount: 10% to 40%, 7 to 14 days. Docs suggest 10-15%. Set up before release. Exempt from the 30-day release cooldown.
- Normal discounts: 10% to 95%, 1 to 14 days.
- 30-day cooldown between discounts (raised from 28 days on January 1, 2023).
- Seasonal Sale discounts made in the Discount Management Dashboard are exempt from the 30-day discount cooldown. A product still in a release or price-increase cooldown cannot join a Seasonal Sale.
- Discounts of 20% or more trigger wishlist emails (the page also says "can" in another place).

## 6. AI content disclosure

Source: [S14]. Secondary: [X1], [X2].

- The Content Survey has two categories. Pre-Generated: content made with AI tools during development and "consumed by players". Valve reviews it like any other content. Live-Generated: content made by AI while the game runs. You must describe your guardrails. [S14]
- The page says: "Efficiency gains through the use of these tools is not the focus of this section." Examples of covered content: artwork, sound, narrative, localization. [S14]
- What changed: secondary press (Notebookcheck and others) report a January 2026 update that narrowed disclosure to content players see, hear or interact with, and exempted behind-the-scenes tools such as code assistants. The primary page carries no change date, so the January 2026 date is UNVERIFIED on a primary source. The current wording on [S14] matches the narrowed scope.
- How the disclosure shows on the store page: UNVERIFIED (not stated on [S14]). Secondary sources say an AI disclosure appears on the store page.

## 7. Reviews, keys and Curator Connect

Sources: [S15], [S16], [S17].

- No reviews in exchange for games, DLC, money or other rewards. The only exception is sending copies to press or creators for previews or reviews. [S15]
- Do not ask for reviews from inside the game. Do not manipulate the review system (for example multiple accounts, coercing players). Violating reviews are banned and removed from the score. [S15]
- Reviewers who got a free copy should disclose it. Only purchases count toward the score, not key activations. Pre-release copies produce reviews labelled "Pre-Release Reviews". [S15]
- Keys: up to 5,000 default release keys; more reviewed case by case. Release State Override keys are for small betas and press/influencer access, generally limited to 2,500, and must never be sold. Playtest keys must never be sold. Dev Comp keys never go to customers. [S16]
- Do not give keys away free unless the same deal is offered on Steam, unless the giveaway is under 100 keys. [S16]
- Fraudsters impersonate journalists and stores to get keys. "Treat keys like cash." [S16]
- Key reselling by third parties: policy beyond the fraud warning is UNVERIFIED.
- Curator Connect: send to up to 100 Curators, up to 5 copies each. Needs a public (at least Coming Soon) page and an uploaded build. Copies work before release. Accepted copies cannot be revoked. Curators need not accept or review. Inactive curators (6 months) may not appear. Needs the "Generate CD Keys" permission. [S17]

## 8. Playtests and demos

Sources: [S18], [S12].

- Playtest: free, no separate store page; a signup section on the base game's page. Players are let in in random batches, or signups can be open. Charging is not allowed (use Early Access for paid). Playtest players cannot review the main game. Joining or leaving does not touch the wishlist. Over 50,000 keys is "effectively an open beta". [S18]
- Demo: a separate App ID of type "Demo" linked to the base game. Optional separate demo store page needs a trailer and at least five demo-specific screenshots. Demo reviews exist only on that separate page. No own community hub. No matchmaking between demo and full game. Achievements in demos discouraged. One wishlist notification within 14 days of first release. [S12]
